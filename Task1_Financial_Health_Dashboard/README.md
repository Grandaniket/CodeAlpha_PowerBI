# Financial Health Dashboard | CodeAlpha PowerBI Internship

## Problem Statement -
To develop an interactive Financial Health Dashboard in PowerBI that analyzes an organization's financial status by visualizing income statements, balance sheets and cash flows, identifying profitability trends over time and providing revenue forecasting to support budgeting, financial planning and data driven decision making.

## Tools Used -
1. Microsoft Power BI
2. Power Query
3. DAX (Data Analysis Expressions)
4. Microsoft Excel / CSV Dataset

## Project Workflow -
1. Imported the financial dataset into Power BI.
2. Cleaned and transformed the data using Power Query.
3. Verified data types and prepared the dataset for analysis.
4. Created DAX measures for KPIs and financial calculations.
5. Designed an Executive Financial Dashboard with interactive visuals.
6. Developed a Forecasting & Financial Insights dashboard featuring revenue forecasting and financial ratio analysis.
7. Created visualizations including KPI cards, line charts, bar charts, donut charts, scatter plots and slicers.
8. Analyzed revenue, gross profit, net income, EBITDA, cash flow, shareholder equity, market capitalization, profitability ratios and debt to equity ratio.
9. Implemented interactive filters for company, category and year to improve user experience.
10. Generated business insights to evaluate financial performance and support strategic decision making.
